⚡ Goenma TrafTest - Guía Rápida de Métricas y Controles

🎮 Controles en Vivo

  • ⏸ Pause / Reanudar: Detiene el envío de tráfico temporalmente para inspeccionar el estado del servidor.
  • ⏹ Stop: Finaliza la prueba inmediatamente y congela las métricas finales.
  • 💾 Export: Descarga al instante el reporte en formato JSON o Markdown sin recargar la página.

⏱️ ¿Cómo interpretar los Percentiles de Latencia?

p50 (Mediana)

El 50% de las peticiones respondieron más rápido que este valor. Representa la experiencia típica.

p95

El 95% de las peticiones fueron más rápidas. Muestra cómo se comportan los casos más lentos.

p99

El 1% de peticiones más pesadas. Vital para detectar cuellos de botella y picos de latencia.

Throughput (RPS)

Peticiones procesadas exitosamente por segundo en cada instante.

💻 Comandos CLI Frecuentes

# 1. Probar con un servidor público (si no tienes API local corriendo)
traftest https://jsonplaceholder.typicode.com/posts/1 -c 5 -r 10 -d 10s

# 2. Benchmark con 20 workers y 100 req/s durante 30s
traftest http://localhost:8080/api/users -c 20 -r 100 -d 30s

# 3. Petición POST con JSON y Header de Autenticación
traftest http://localhost:8080/api/items -X POST -H "Authorization: Bearer mytoken" -b '{"name":"item1"}'

# 4. Modo Terminal Interactiva (TUI) con exportación
traftest --cli http://localhost:8080/health -c 10 -n 1000 -o report.md
